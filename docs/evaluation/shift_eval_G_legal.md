## 法的リスク詳細分析

### 🔴 リスク度：高

#### 1. 週法定労働時間（40時間）のチェック不足

**問題の詳細**:
- 最適化エンジン（`optimizer/engine.py`）に週40時間超過を防ぐ制約がない
- 正職員の実働時間: 月火金8時間、水7時間、木土4時間
- 例: 月（8h）+ 火（8h）+ 水（7h）+ 木（4h）+ 金（8h）+ 土（4h）= **39時間** → ギリギリ適法
- しかし、週によっては40時間を超える可能性がある

**法的要件**:
- 労働基準法第32条: 使用者は、労働者に、休憩時間を除き1週間について40時間を超えて、労働させてはならない

**リスク**:
- 週40時間を超える勤務が発生した場合、36協定なしでは労働基準法違反となる
- 労働基準監督署から是正勧告を受けるリスク
- 最悪の場合、6ヶ月以下の懲役または30万円以下の罰金（労働基準法第119条）

**根拠ファイル**:
- `optimizer/engine.py:328-416` 最適化ロジック全体
- `optimizer/engine.py:431-476` ハード制約（週労働時間制約なし）

#### 2. 36協定に基づく時間外労働管理機能の欠如

**問題の詳細**:
- 時間外労働時間の記録・管理・上限チェック機能がない
- 要件定義書に36協定関連要件が記載されていない
- 残業時間の計上・集計機能がない

**法的要件**:
- 労働基準法第36条: 時間外労働を行う場合、労使協定（36協定）を締結し、労働基準監督署に届け出る必要がある
- 時間外労働の上限規制:
  - 原則: 月45時間、年360時間
  - 特別条項: 月100時間未満、年720時間、2-6ヶ月平均80時間

**リスク**:
- 36協定なしで時間外労働を行った場合、労働基準法違反となる
- 上限規制違反は罰則の対象（6ヶ月以下の懲役または30万円以下の罰金）
- 長時間労働による健康被害のリスク

**根拠ファイル**:
- `REQUIREMENTS.md:345-371` 制約条件の記載（36協定に関する記載なし）
- `optimizer/engine.py` 全体（残業時間管理機能なし）

def _constraint_weekly_hours(self) -> None:
    """週法定労働時間制約: 週40時間を超えない"""
    for week_start_date in self._get_week_start_dates():
        week_dates = self._get_dates_in_week(week_start_date)
        for emp in self.employees:
            # 週の実働時間を計算
            total_hours = sum(
                self._get_work_hours(emp, d, area)
                for d in week_dates
                for area in [Area.REHA.value, Area.RECEPTION.value]
                if (emp.id, d, area) in self.x and pulp.value(self.x[(emp.id, d, area)]) == 1
            )
            # 40時間を超えないように制約
            self.problem += total_hours <= 40
```

def _constraint_consecutive_days(self) -> None:
    """連続勤務日数制約: 最大6日まで"""
    MAX_CONSECUTIVE_DAYS = 6
    for emp in self.employees:
        for i in range(len(self.dates) - MAX_CONSECUTIVE_DAYS):
            consecutive_dates = self.dates[i:i+MAX_CONSECUTIVE_DAYS+1]
            # 7日連続勤務を禁止
            self.problem += (
                pulp.lpSum(
                    self.x[(emp.id, d, area)]
                    for d in consecutive_dates
                    for area in [Area.REHA.value, Area.RECEPTION.value]
                    if (emp.id, d, area) in self.x
                ) <= MAX_CONSECUTIVE_DAYS
            )
```

## まとめ

### 総合評価

shift-scheduler-claudeは、**基本的な労働法令要件（法定休日、休憩時間）は遵守**しているが、**週法定労働時間のチェック、36協定対応、変形労働時間制の明示が不足**している。

### 緊急対応が必要な項目

1. **週法定労働時間チェック機能の追加**（リスク度：高）
2. **36協定対応機能の追加**（リスク度：高）
3. **変形労働時間制の明示**（リスク度：中）

### 推奨される対応順序

1. **フェーズ1（緊急対応）**: 週法定労働時間チェック機能の追加、36協定対応機能の追加
2. **フェーズ2（重要対応）**: 変形労働時間制の明示、個人情報保護方針の策定、連続勤務日数制限の実装
3. **フェーズ3（改善対応）**: 医療業種特有の労働規制への対応検討、均等待遇検証機能の追加、ハラスメント防止機能の追加

### 結論

本システムは、診療所のシフト作成を効率化する優れたツールであるが、**労働法令遵守の観点から、週法定労働時間チェック機能と36協定対応機能の追加が急務**である。これらの機能を追加することで、労働基準法違反のリスクを大幅に低減できる。

また、実際の運用では、**変形労働時間制の労使協定、就業規則への記載、36協定の締結と届出**など、システム外の法的要件も遵守する必要がある点に留意されたい。
