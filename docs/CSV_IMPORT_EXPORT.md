# CSV入出力機能の使い方

## 概要

職員管理画面にCSV出力・取り込み機能が追加されました。この機能により、職員データの一括管理や外部ツールとの連携が可能になります。

## 機能

### 1. CSV出力（エクスポート）

登録されている職員データをCSV形式でダウンロードできます。

**手順:**
1. 職員管理画面を開く
2. 「CSV入出力」タブを選択
3. 「CSVダウンロード」ボタンをクリック
4. `employees.csv`ファイルがダウンロードされます

**出力される項目:**
- 名前
- 職員タイプ (TYPE_A, TYPE_B, TYPE_C, TYPE_D, TYPE_E, TYPE_F)
- 雇用形態 (正職員, パート)
- 勤務パターンID
- パターン固定 (True/False)
- リハ室スキル (0-100)
- 受付午前スキル (0-100)
- 受付午後スキル (0-100)
- 総合対応力 (0-100)

### 2. CSV取り込み（インポート）

CSVファイルから職員データを一括登録できます。

**手順:**
1. 職員管理画面を開く
2. 「CSV入出力」タブを選択
3. 既存職員の扱いを選択:
   - **保持する（追加のみ）**: 既存の職員データはそのまま残し、新しいデータを追加
   - **削除してから取り込む**: 既存の職員データをすべて削除してから取り込み
4. CSVファイルを選択してアップロード
5. プレビューで内容を確認
6. 「取り込み実行」ボタンをクリック

**注意事項:**
- ファイルはUTF-8エンコードで保存してください
- ヘッダー行は必須です
- 職員タイプに応じて、使用しないスキルは0に設定してください
  - TYPE_B, TYPE_E, TYPE_F（受付専任）: リハ室スキル = 0
  - TYPE_C, TYPE_D（リハ室専任）: 受付午前スキル = 0, 受付午後スキル = 0

## CSVフォーマット

### サンプル

```csv
名前,職員タイプ,雇用形態,勤務パターンID,パターン固定,リハ室スキル,受付午前スキル,受付午後スキル,総合対応力
山田太郎,TYPE_A,正職員,full_early,False,80,75,75,70
鈴木花子,TYPE_B,パート,part_morning,True,0,85,85,60
田中三郎,TYPE_C,正職員,full_late,False,90,0,0,80
```

### 勤務パターンID一覧

**フルタイム（正職員）:**
- `full_early`: 早番 (08:30-17:30)
- `full_mid`: 中番 (09:30-18:30)
- `full_late`: 遅番 (10:30-19:30)

**時短勤務（正職員）:**
- `short_time`: 時短勤務 (09:30-16:00)

**パートタイム:**
- `part_morning_early`: パート早番 (08:30-13:00)
- `part_morning`: パート午前 (09:00-13:00)
- `part_morning_ext`: パート午前延長 (08:30-14:00)

## エラーハンドリング

以下の場合、該当するデータはスキップされます:
- 名前が空
- 職員タイプが無効（TYPE_A～Fのいずれでもない）
- 雇用形態が無効（「正職員」「パート」のいずれでもない）
- スキル値が数値でない
- 必須列が欠けている

正常なデータのみが登録され、エラーのあるデータはスキップされます。

## 使用例

### 例1: Excelで職員データを編集

1. CSV出力で現在のデータをダウンロード
2. Excelで開いて編集（名前の修正、スキルの調整など）
3. UTF-8形式のCSVで保存
4. 「削除してから取り込む」を選択して再インポート

### 例2: 新年度の職員追加

1. CSV出力で現在のデータをダウンロード（テンプレートとして使用）
2. 新規職員のデータを追加
3. 「保持する（追加のみ）」を選択してインポート

### 例3: 他のシステムからデータを移行

1. 他システムから職員データをエクスポート
2. 本システムのCSVフォーマットに変換
3. 「削除してから取り込む」を選択してインポート

## 制限事項

- 取り込み時、職員IDは自動採番されるため、IDの指定はできません
- 勤務パターンIDは事前定義されたもののみ使用可能です
- スキル値は0-100の範囲で指定してください（範囲外の値はエラーになります）

## トラブルシューティング

### 「ファイルの読み込みに失敗しました」というエラーが出る

→ ファイルがUTF-8エンコードで保存されているか確認してください。Excelで保存する場合は「CSV UTF-8（コンマ区切り）」形式を選択してください。

### 「有効な職員データが見つかりませんでした」というエラーが出る

→ CSVのヘッダー行が正しいか、必須列がすべて含まれているか確認してください。

### 一部のデータが取り込まれない

→ エラーのある行はスキップされます。データの形式（職員タイプ、雇用形態、スキル値など）を確認してください。
